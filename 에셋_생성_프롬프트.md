# 설득의 정석 — 에셋 생성 프롬프트

기존 에셋(`life/mom`, `cutscene/owner`, 모든 배경)의 **디지털 일러스트 화풍**에 맞춰 작성했습니다.

## 작업 방법

1. 각 캐릭터의 **[BASE]** 프롬프트로 `normal`을 먼저 생성합니다.
2. 마음에 드는 결과를 고른 뒤, **그 이미지를 레퍼런스로 넣고** [표정 변형] 4개를 각각 생성합니다.
   → 프롬프트만으로는 같은 인물이 나오지 않습니다. 레퍼런스 이미지가 필수입니다.
3. 저장 경로와 파일명을 정확히 맞춥니다.

## 규격

| 구분 | 형식 | 크기 | 비고 |
|---|---|---|---|
| 캐릭터 | PNG | 768 × 1376 (세로) | **투명 배경 필수**, 좌우 여백 10% 이상 |
| 배경 | JPG | 1920 × 1080 (가로) | 사람 없음, 하단 1/3 비워두기 |

- 흰 배경으로 나오면 게임에서 캐릭터 뒤에 **흰 사각형**이 깔립니다.
- 좌우 여백이 없으면 **팔이 잘립니다** (`cutscene/owner.png`가 현재 이 문제).
- 한 인물의 5표정은 **반드시 같은 복장·같은 포즈·같은 머리**여야 합니다.

# 3. 작업 순서

1. **일상 캐릭터 4명** (20장) — `landlord`, `friend`, `neighbor`, `sunbae`
2. **일상 배경 4장** — `life/bg/stage2~5`
3. 여기까지 하면 **일상 트랙 5스테이지를 온전히 플레이할 수 있습니다**
4. 업무 트랙 시나리오 보강 → 그 다음 업무 캐릭터·배경

# 4. 점검

뽑으신 뒤 알려주시면 다음을 자동으로 확인해 드립니다.

- 투명 배경 여부 (흰 배경이면 제거 가능)
- 좌우·상하 잘림 여부
- 크기와 파일명 규격

# 5. 남은 결정

화풍을 일러스트로 통일하기로 하면 `work/jimin`(지민)과 `work/boojang`(정 부장)은 현재 **실사 사진**이라 다시 뽑아야 합니다. 그 두 명의 프롬프트가 필요하시면 같은 형식으로 추가해 드리겠습니다.
